# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проект

Одностраничный лендинг для онлайн-программы **«Сам себе нутрициолог»** (Академия натуропатии «Система здоровья», автор — Марина Жигульская). Коммерческая цель — продажа 30-дневной программы восстановления здоровья женщинам 40+.

## Структура

- `Reference.html` — **единственный рабочий файл**. Это макет/эталон всего сайта: HTML + встроенные CSS и JS в одном файле (~680 строк). Все правки контента, структуры, стилей делаются прямо здесь.
- `Exphoto/` — фотографии спикеров и автора для подстановки в плейсхолдеры `.aph`, `.spk-photo` (сейчас в разметке заглушки-инициалы с комментариями `<!-- Заменить на фото: ... -->`).

Нет build-системы, package.json, тестов, линтеров. Работа ведётся прямым редактированием `Reference.html` — открыть в браузере, увидеть результат.

## Архитектура лендинга

Структура следует классическому маркетинговому нарративу AIDA + StoryBrand. Порядок секций в `Reference.html` несёт смысловую нагрузку — **перестановка ломает нарратив**:

1. **Hero** (строки ~232-280) — оффер + оффер-карточка справа с CTA на `#pricing`
2. **Stats** (~283-290) — социальное доказательство цифрами (6000 учеников, 93%, 30 дней)
3. **Pain/Symptoms** `#symptoms` (~293-311) — 9 карточек болей на языке клиента
4. **Insight** (~314-361) — **ключевая идея продукта**: «разные симптомы — одна причина». Это Big Idea/Unique Mechanism всего оффера. Визуальная схема симптомы→причина→результат.
5. **Results** (~364-397) — кейсы учениц (before/after)
6. **Program** `#program` (~400-467) — табы с 3 модулями + предобучение, 26 уроков с benefit-линиями (`→ ...`)
7. **Format** (~470-479) — как устроено обучение
8. **Bonuses** (~482-493) — 6 бонусных модулей
9. **About** `#about` (~496-526) — автор Марина Жигульская
10. **Speakers** (~531-576) — три доп. спикера
11. **Pricing** `#pricing` (~579-641) — сравнение «путь по кругу vs программа» + два тарифа (149k / 189k ₸)
12. **FAQ** (~644-656) — 7 вопросов, раскрываются JS-функцией `tfaq()`
13. **Final CTA** (~659-675) + **Footer** (~677-680)

**Навигация** (`nav`, ~220-229) якорно связана с `#symptoms`, `#program`, `#about`, `#pricing`.

## Стили и дизайн-токены

Все цвета и стили вынесены в CSS custom properties в `:root` (строка 9):
- `--navy` `#1B2E5E` — основной тёмный (текст, тёмные секции)
- `--blue` `#2E7BB4` — акцент, CTA, ссылки
- `--gold` `#E8A82A` — второй акцент, главные CTA, premium-элементы
- `--blue-pale`, `--blue-soft`, `--sky` — нейтральные фоны
- `--red-soft` `#E85D5D`, `--green-soft` `#27AE60` — для «до/после», скидочных бейджей

**Правило**: для новых элементов **всегда использовать переменные**, не хардкодить hex. Единственное исключение — inline-стили у декоративных `.blob` (радиусы, позиции).

**Типографика**: Montserrat (300-800) для основного текста, Playfair Display (italic) для акцентных цитат в insight-секции и заглушек фото.

**Именование классов** — сверхкороткие двух-трёхбуквенные аббревиатуры (`hc`, `hs`, `pcrd`, `mhdr`, `rcat-gut`). При добавлении новых секций **сохранять этот стиль**, не писать длинные БЭМ-имена.

**Адаптив**: используется `clamp()` для fluid typography, `grid-template-columns` с фиксированными колонками. Медиа-запросы для мобильных в файле **отсутствуют** — это известный пробел; при правках на мобильной адаптации добавлять медиа-блок в конец `<style>`.

## JavaScript

Два минимальных инлайн-скрипта в конце файла (~682-685):
- `stab(id, btn)` — переключение табов модулей программы
- `tfaq(el)` — accordion для FAQ (закрывает другие при открытии одного)

JS намеренно написан в одну строку без форматирования. При добавлении новой интерактивности **держать её такой же минималистичной**, не тянуть библиотеки.

## Принципы работы с контентом

Проект — **коммерческий лендинг**, поэтому изменения в текстах оцениваются с маркетинговой точки зрения:

- **Нарратив «одна причина — много симптомов»** — это якорь всего оффера. Тексты в hero, insight, FAQ, final-CTA должны поддерживать эту идею. Не размывать её новыми «продуктовыми фичами».
- **Медицинские заявления** (кейсы в `#results`, особенно про «операцию не понадобилась», «узлы рассосались», «папилломы исчезли») юридически чувствительны. При правках не усиливать формулировки без согласования.
- **Язык болей** (pain-секция) написан от первого лица клиента — при добавлении новых симптомов сохранять тот же голос («стыдно…», «врезаются…», «к вечеру нет сил…»), а не клинические термины.
- **Цены указаны в ₸/₽/$** — при правке одной суммы обновлять все три валюты одновременно (см. `.pamt`, `.pcur`, `.fpn`).
