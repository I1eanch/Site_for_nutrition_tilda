# Браузерное Расширение Antigravity

**Источник:** [https://antigravity.im/browser-extension](https://antigravity.im/browser-extension)

Браузерное расширение Google Antigravity позволяет агенту (через специальный Browser Subagent) взаимодействовать с браузером Chrome: проводить UI-тестирование, делать скриншоты, считывать DOM и записывать видео сессий.

Связанные термины: [[Antigravity]], [[Agent_Manager]], [[Browser_Automation]], [[UI_Testing]].

## Ключевые возможности
- **Визуальное тестирование:** Агент "видит" DOM, может кликать, вводить текст и проверять верстку.
- **Поддержка Agent Manager:** Возможность запуска нескольких агентов параллельно для работы с разными вкладками.
- **WSL:** Интеграция работает из среды WSL 2 (Windows Subsystem for Linux), обращаясь к Chrome, установленному в основной системе Windows (через Native Messaging).

## Решение проблем (Troubleshooting)
1. **Проблема подключения:**
   - Расширение работает через **Native Messaging**. Если оно не может подключиться, нужно полностью перезапустить Chrome (закрыть все окна) и убедиться, что расширение активно в `chrome://extensions`.
2. **Агент не может взаимодействовать со страницей:**
   - Страница не успела загрузиться.
   - Политики безопасности (CORS / CSP) блокируют автоматизацию.
   - Элементы находятся в Shadow DOM.
3. **Не работает под WSL:**
   - Убедитесь, что задана переменная окружения `BROWSER` с путем до Windows-версии Chrome: `export BROWSER="/mnt/c/Program Files/Google/Chrome/Application/chrome.exe"`.
